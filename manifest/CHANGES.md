# 매니페스트 변경 기록

기준값·항목·등급을 바꿀 때마다 여기에 적는다. 「제안」 값을 바꾸거나 새 절대 기준을 넣을 때는 근거를 함께 남긴다. 한 프로젝트에만 해당하는 값은 이 파일이 아니라 그 프로젝트의 프로필 `[overrides]`에 둔다.

버전 규칙
- 패치(1.0.x): 설명·메모·수집기 이름처럼 판정에 영향이 없는 변경
- 마이너(1.x.0): 잡음 등급·판정 방식·기준값·지표 키 변경, 항목의 층 추가·삭제
- 메이저(x.0.0): 항목 추가·삭제, ID 변경

해시는 `python -m perfkit manifest hash`로 본다. 버전과 해시는 회차 메타·결과·비교에 그대로 남으므로, 버전이 다른 결과끼리 비교할 때는 바뀐 항목을 확인한다.

## 1.0.0 (2026-11-26)

- 처음 판. 공개 문서(Unity Manual·URP·Android Developers·Play 도움말·Arm·Qualcomm) 조사 기반 점검 항목 123개(FRM 5·CPU 15·SCR 9·GPU 25·MEM 18·AST 20·BLD 13·THM 7·STB 11). 출처는 `sources` 칸.
- 세트: 기본 73(그중 5개는 심화 변형 `deep_variant`), 심화 50. 세트가 정해지지 않았던 GPU-14는 심화, MEM-05는 기본(제안, `set_basis`에 표시).
- 층: 정적 → L0, 빌드 → L1, 에디터 Play → L2, 기기 → L3-D, 콘솔 → console. 에뮬레이터 등급 L3-E는 19항목(프레임 시간·CPU 메인·렌더, GC, 메모리 점유, SetPass·정점, 로드 시간, logcat 예외·종료 사유). 발열·GPU 클럭·GPU 사용량·배터리·전력·GPU ms·GPU 하드웨어 카운터는 `emulator_forbidden_tags`로 막음.
- 판정: 절대 기준은 L0·L1·L3-D·console에만. L2는 추세용, L3-E는 변화만. 절대 기준 숫자는 공식 수치(출처 번호)와 1판 제안값이고, 규칙마다 근거(공식·제안·프로젝트가 정함)를 남김.
- 잡음: L0·L1은 none, L2·L3-D는 항목표 값. L3-E는 모두 `pending_aa`(프로젝트가 A/A 잡음 바닥을 잰 뒤 프로필에서 채움).
- 보조 지표 AUX-01~04(프로세스·스레드 CPU 점유율, 시스템 부하, 로드 구간 시간). 123항목 밖이며 항목 수 검사에 세지 않음.
- 단위 환산: Play 메모리 한도의 GB 표기는 1GB = 1000MB로 옮김(MEM-01·MEM-08·BLD-03). GiB인지는 확인 필요.
